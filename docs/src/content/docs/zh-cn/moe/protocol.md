## 两个赛道

两个赛道复现 Marin 的 "May Recipe" compute-optimal Grug MoE 单元（`moe_may_compute_opt_d768_ep1` 和
`moe_may_compute_opt_d1024_ep1`）的结构、上下文、batch 和更新步数。

| | **d768** | **d1024** |
|---|---|---|
| 宽度 / 层数 | 768 / 8 | 1024 / 11 |
| 注意力 | 6 个 query 头，1 个 KV 头，头维度 128 | 8 个 query 头，2 个 KV 头，头维度 128 |
| 全注意力层（其余层为 2,048 滑窗） | 3、7 | 3、7、10 |
| 路由专家 | 256 个 SwiGLU，宽 384，选 4 | 256 个 SwiGLU，宽 512，选 4 |
| 共享专家 | 1 个 SwiGLU，宽 768 | 1 个 SwiGLU，宽 1024 |
| 总参数 / 激活参数 | 1,992,831,744 / 209,203,968 | 4,701,051,904 / 341,072,896 |
| 上下文 | 4,096 | 4,096 |
| 每步 token | 64 × 4,096 = 262,144 | 128 × 4,096 = 524,288 |
| 更新步数 | 16,875 | 16,080 |
| **训练 token** | **4,423,680,000** | **8,430,551,040** |
| **每 token 训练 FLOPs（anchor）** | **915,429,888** | **1,656,268,800** |
| 训练总 FLOPs | 4.0496 × 10¹⁸ | 1.3963 × 10¹⁹ |
| 换算成 Marin 口径 | 2.797 × 10¹⁸（Marin：2.81 × 10¹⁸） | 1.152 × 10¹⁹（Marin：1.16 × 10¹⁹） |
| CORE-22 + LC-5 评测步 | 4,000 / 8,000 / 12,000 / 16,875 | 4,000 / 8,000 / 12,000 / 16,080 |

## 受控项

- **数据**：`xjxyys/dolma3_hq_300B_shuffled_clean`，固定 revision。
  - 训练 shard 按 00000、00001… 顺序读取，00255 作为开发集，6 个验证文件留作正式评测。
- **分词器**：dolma2，词表 100,278，embedding 补齐到 100,352。
- **打包**：每篇文档前加 `<|endoftext|>`，按文件顺序拼接。第 k 行取 token [4096k, 4096k+4097)。
- **数据顺序**：第 u 步读取第 uR 到 (u+1)R 行（R 为每步行数）。各 rank 均分，micro-batch 按顺序切分，因此与 world size 无关。
- **随机种子**：42。
- **优化器**：AdamW，β = (0.9, 0.95)。
  - 只对矩阵做 0.1 的 weight decay，梯度裁剪 1.0。
  - 前 1% 的步数线性 warmup，之后线性衰减到 0。
  - 峰值学习率按 Marin 的经验公式算出：d768 为 0.00193，d1024 为 0.00203。
- **精度**：参数和计算用 bf16，梯度规约和路由器用 fp32（FSDP2）。
- **算力**：准入时每 token FLOPs 与 anchor 相差不超过 1%，整个训练累计不超过 2%。
  - matmul FLOPs 在 CPU 上逐 block 实测。
  - softmax 注意力按因果边或滑窗边计费。

## 吞吐

`moe.throughput` 直接复用训练器的 update。
- 10 步预热，30 步计时，去掉最快和最慢各 10%。
- 每次在同一节点上先后测 baseline 和待测方法，发布两者的**相对吞吐**。
- 同时报告 tokens/s、每卡 tokens/s、MFU（峰值按 989.4 TFLOP/s 计）和显存峰值。

规划参考值（8 卡）：d768 约 890,600 tok/s（1.38 小时），d1024 约 664,300 tok/s（3.53 小时）。这两个数是按 Marin
8 卡 MoE 的 MFU 估算的，不是实测。

## 评测

- **验证 BPB**：在 6 个验证源上分别计算 BPB，再取宏平均。
- **CORE-22**：与稠密排行榜完全相同，prompt 从左截断到 4,096。
- **LC-5**：每个任务每个长度 100 个确定性样本，长度为 2,048 / 3,072 / 4,096。
  - 任务：passkey、niah_single、niah_multikey、niah_choice（四选一，按 25% 中心化）、var_tracking。
  - 8,192 长度只作外推探针，不计分。
- **MoE-CORE**：对 27 项中心化准确率取平均，即 (22 × CORE-22 + 5 × LC-5) / 27。
- **长文档 BPB**：在长度不少于 4,097 的验证文档上，比较位置 0–2,047 和 2,048–4,095 的 BPB。
